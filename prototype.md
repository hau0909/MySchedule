#### My Schedule (web-app: timeline task manager)

### Tech stack: MERN Project

1. Front-end: NextJs (ReactJs)
2. Backend: ExpressJs
3. Database: MongoD
4. UI/Style/Component: Shadcn/CSS/tailwindcss

## Goal:

# 1. Manage Task and Timeline

# 2. Show clearly schedule

# 3. Easy to drag and drop to manage

# 4. AI system to support manager

---

## Core Feature:

# 1. Task time

- CRUD task
- Drag & Drop item to schedule

# 2. timeline

- Set goal
- Add/Remove task to timeline

# 3. schedule

- Show task and timeline on schedule
- Noti experied task
- Add/Remove task to schedule

# 4. AI support

- Chatting with AI about task detail
- CRUD task item throught the message
